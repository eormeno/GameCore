A modern web-based game development framework

GameCore Framework

GameCore is a lightweight, modular framework for building browser-based games with modern JavaScript. Whether you're creating simple 2D games or complex interactive experiences, GameCore provides the tools and structure you need to build scalable, maintainable game applications.

Key Framework Concepts

GameObject

The fundamental building block in GameCore. GameObjects are containers that hold components and can be positioned within the game world. Every entity in your game - from players to enemies to UI elements - is represented as a GameObject.

// Creating a simple GameObject
const player = new GameObject({
  id: 'player',
  position: { x: 100, y: 100 },
  components: [new SpriteComponent('player-sprite')]
});

Components

Components add behavior and functionality to GameObjects. Each component handles a specific aspect like rendering, physics, input handling, or game logic. This component-based architecture promotes code reuse and separation of concerns.

// Component example
class MovementComponent extends Component {
  update(deltaTime) {
    // Update position based on velocity and time
    this.gameObject.position.x += this.velocity.x * deltaTime;
    this.gameObject.position.y += this.velocity.y * deltaTime;
  }
}

Prefabs

Templates for creating GameObjects with predefined components and properties. Prefabs allow you to define a complex GameObject once and instantiate it multiple times, which is perfect for common game elements like enemies, projectiles, or collectibles.

// Defining a prefab
const enemyPrefab = {
  components: [
    { type: 'sprite', properties: { spriteSheet: 'enemies', frame: 0 } },
    { type: 'physics', properties: { mass: 1, friction: 0.1 } },
    { type: 'ai', properties: { behavior: 'patrol' } }
  ]
};

// Creating an instance from prefab
const enemy = GameObjectFactory.createFromPrefab(enemyPrefab);

Services

Global systems that provide functionality across your game. Services handle cross-cutting concerns like asset loading, input management, physics simulation, rendering, and audio. They're singleton objects accessible throughout your game code.

// Using the input service
InputService.onKeyDown('Space', () => {
  player.jump();
});

// Using the audio service
AudioService.playSound('explosion', { volume: 0.8, pitch: 1.2 });

Events

GameCore uses an event system for communication between decoupled parts of your game. Components, services, and game logic can publish and subscribe to events, enabling loose coupling and modular design.

// Publishing an event
EventBus.publish('player:hit', { damage: 10 });

// Subscribing to an event
EventBus.subscribe('player:hit', (data) => {
  updateHealthUI(data.damage);
});

GameApp

The main application container that coordinates the game loop, manages scenes, and initializes core services. Your game starts by creating a GameApp instance and configuring its settings.

// Creating and starting a game
const myGame = new GameApp({
  canvas: document.getElementById('gameCanvas'),
  width: 800,
  height: 600,
  scenes: [LoadingScene, MainMenuScene, GameplayScene]
});

myGame.start();

Scenes

Containers for game states like menus, levels, or screens. Each scene has its own collection of GameObjects and logic. The GameApp manages transitions between scenes.

class LevelOneScene extends Scene {
  init() {
    // Create level objects
    this.addGameObject(new Terrain('level1-map'));
    this.addGameObject(new Player({ x: 50, y: 50 }));
    // Add enemies, collectibles, etc.
  }

  update(deltaTime) {
    // Scene-specific update logic
    this.checkWinCondition();
  }
}
