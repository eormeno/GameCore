GameCore: Framework para Videojuegos Autoritativos

Emilio Ormeño, Cintia Ferrarini Oliver - UNSJ

RESUMEN

Framework backend que ofrece una plataforma robusta y escalable para implementar videojuegos autoritativos, integrando mecanismos avanzados de sincronización, autenticación, gestión de estados y eventos para garantizar la integridad y seguridad en entornos multijugador.
