Sistema de Ítems para Plataformas de Videojuegos en Laravel

Fecha: 2025-04-30

Autor: eormeno-idei

Introducción

Este documento presenta una arquitectura completa para un sistema de ítems para plataformas de videojuegos implementado en Laravel. El sistema está diseñado para manejar una gran variedad de tipos de ítems incluyendo cuantificables, físicos, contenedores, interactuables, compartidos, consumibles y temporales.

Descripción de Elementos

1. Ítem Base

El concepto fundamental en este sistema. Un ítem es cualquier entidad que puede ser poseída, transferida, y puede tener comportamientos definidos. Todos los ítems compartirán ciertas propiedades como identificador único, nombre, descripción y estado.

2. Tipos de Ítems

  • Ítems Cuantificables: Representan recursos como puntos, vida, monedas, etc.
  • Ítems Físicos: Representan objetos concretos como cartas, fichas, armas, etc.
  • Ítems Contenedores: Pueden contener otros ítems (mazo, inventario, slot).
  • Ítems Interactuables: Tienen funcionalidades con las que el jugador puede interactuar.
  • Ítems Compartidos: Pueden ser accedidos o utilizados por múltiples jugadores.
  • Ítems de Estado: Representan estados del juego como rondas, turnos, etc.
  • Ítems Consumibles: Pueden agotarse después de un número determinado de usos.
  • Ítems Temporales: Expiran después de un período de tiempo determinado.

3. Propiedad

Define quién posee un ítem, pudiendo ser:

  • Jugador específico
  • Grupo de jugadores
  • Sistema (ítems no poseídos por ningún jugador específico)
  • Compartido (accesible por ciertos jugadores o todos)

4. Reglas

Sistema basado en eventos que define el comportamiento de los ítems mediante un lenguaje de script simple.

    public function acquire($owner)
    {
        $oldOwner = $this->owner;
        $this->owner()->associate($owner);
        $this->save();

        event(new ItemAcquired($this, $owner, $oldOwner));
        $this->executeRules('ACQUIRE', [
            'new_owner' => $owner,
            'old_owner' => $oldOwner
        ]);

        return $this;
    }

    public function release()
    {
        $oldOwner = $this->owner;
        $this->owner()->dissociate();
        $this->save();

        event(new ItemReleased($this, $oldOwner));
        $this->executeRules('RELEASE', [
            'old_owner' => $oldOwner
        ]);

        return $this;
    }

    public function transfer($newOwner)

        $oldOwner = $this->owner;

        $this->save();

        event(new ItemTransferred($this, $newOwner, $oldOwner));
        $this->executeRules('TRANSFER', [
            'new_owner' => $newOwner,

    // Método para utilizar un ítem consumible
    public function consume($amount = 1)
    {
        if (!$this->isConsumable()) {
            throw new \Exception("This item cannot be consumed");
        }

        if ($this->state === 'consumed') {
            throw new \Exception("Item already fully consumed");
        }

        $consumable = $this->consumable;

        if ($consumable->uses_remaining <= 0) {
            throw new \Exception("No uses remaining for this item");
        }

        // Si es stackable, reducimos el stack_size primero
        if ($consumable->is_stackable && $consumable->stack_size > 1) {
            $consumable->stack_size -= $amount;
            $consumable->save();

            $this->executeRules('CONSUME', [
                'amount' => $amount,
                'uses_remaining' => $consumable->uses_remaining,
                'stack_size' => $consumable->stack_size
            ]);

            return $this;
        }

        // Si no es stackable o el stack es de tamaño 1, reducimos los usos
        $consumable->uses_remaining -= $amount;
        $consumable->save();

        // Si se agotaron los usos, marcar como consumido
        if ($consumable->uses_remaining <= 0) {
            $this->state = 'consumed';
            $this->save();

            event(new ItemConsumed($this));
        }

        $this->executeRules('CONSUME', [
            'amount' => $amount,
            'uses_remaining' => $consumable->uses_remaining
        ]);

        return $this;
    }

    // Método para verificar y manejar la expiración
    public function checkExpiration()
    {
        if ($this->isExpired() && $this->state !== 'consumed') {
            $this->state = 'consumed';
            $this->save();

            event(new ItemExpired($this));
            $this->executeRules('EXPIRE');

            return true;
        }

        return false;
    }

    // Ejecución de reglas
    public function executeRules($eventType, $data = [])
    {
        $context = [
            'item' => $this,
            'event' => [
                'type' => $eventType,
                'data' => $data
            ]
        ];

        foreach ($this->rules as $rule) {
            $ruleEngine = app(RuleEngine::class);

            if ($ruleEngine->evaluateCondition($rule->condition_script, $context)) {
                $ruleEngine->executeAction($rule->action_script, $context);
            }
        }
    }

    // Interacción entre ítems
    public function interact(Item $other, $action)
    {
        $this->executeRules('INTERACT', [
            'target' => $other,
            'action' => $action
        ]);

        return $this;
    }
}

    /**
     * Método para añadir usos al ítem
     */
    public function addUses(int $amount)
    {
        $this->uses_remaining = min($this->uses_remaining + $amount, $this->max_uses);
        $this->save();

        // Si el ítem estaba consumido y ahora tiene usos, lo activamos de nuevo
        if ($this->item->state === 'consumed' && $this->uses_remaining > 0) {
            $this->item->state = 'active';
            $this->item->save();
        }

        return $this;
    }

    /**
     * Método para aumentar el tamaño del stack
     */
    public function increaseStack(int $amount = 1)
    {
        if (!$this->is_stackable) {
            throw new \Exception("This item is not stackable");
        }

        $this->stack_size += $amount;
        $this->save();

        return $this;
    }

    /**
     * Método para dividir un stack en dos
     */
    public function splitStack(int $amount)
    {
        if (!$this->is_stackable) {
            throw new \Exception("This item is not stackable");
        }

        if ($amount >= $this->stack_size) {
            throw new \Exception("Cannot split: requested amount exceeds stack size");
        }

        // Crear un nuevo ítem con las propiedades del original
        $newItem = $this->item->replicate();
        $newItem->push();

        // Crear un nuevo consumible para el nuevo ítem
        $newConsumable = $this->replicate();
        $newConsumable->item_id = $newItem->id;
        $newConsumable->stack_size = $amount;
        $newConsumable->save();

        // Reducir el stack original
        $this->stack_size -= $amount;
        $this->save();

        // Transferir al mismo dueño
        if ($this->item->owner) {
            $newItem->acquire($this->item->owner);
        }

        return $newItem;
    }
}

    /**
     * Configurar la fecha de expiración
     */
    public function expiresIn($duration)
    {
        // $duration puede ser un int (segundos) o una cadena como '2 hours', '1 day', etc.
        if (is_numeric($duration)) {
            $this->expires_at = Carbon::now()->addSeconds($duration);
        } else {
            $this->expires_at = Carbon::now()->add($duration);
        }
        $this->save();

        return $this;
    }

    /**
     * Extiende la duración del ítem
     */
    public function extend($duration)
    {
        if (is_numeric($duration)) {
            $this->expires_at = $this->expires_at->addSeconds($duration);
        } else {
            $this->expires_at = $this->expires_at->add($duration);
        }
        $this->save();

        return $this;
    }

    /**
     * Verifica si el ítem está expirado
     */
    public function isExpired()
    {
        return $this->expires_at && $this->expires_at->isPast();
    }

    /**
     * Obtiene el tiempo restante hasta la expiración
     */
    public function remainingTime()
    {
        if (!$this->expires_at) {
            return null;
        }

        if ($this->isExpired()) {
            return 0;
        }

        return Carbon::now()->diffInSeconds($this->expires_at);
    }
}

     * Verificar todos los ítems temporales para expiración
     */
    public function checkExpiredItems()
    {
        $expiredItems = Item::whereHas('temporal', function ($query) {
            $query->where('expires_at', '<=', Carbon::now());
        })
        ->where('state', '!=', 'consumed')
        ->get();

        foreach ($expiredItems as $item) {
            $item->checkExpiration();
        }

        return $expiredItems;
    }

Consideraciones Adicionales

1. Rendimiento

  • Implementar índices en las columnas temporales como expires_at para mejorar las consultas de expiración.
  • Considerar almacenar en caché los ítems frecuentemente accedidos o sus propiedades.

2. Escalabilidad

  • Para grandes volúmenes de ítems temporales, considerar una tabla separada para rastrear solo los próximos a expirar.
  • Implementar una cola de trabajos para procesar la expiración de ítems de manera asíncrona.

3. UX (Experiencia de Usuario)

  • Implementar notificaciones para alertar a los jugadores sobre ítems próximos a expirar.
  • Mostrar contadores visuales para los usos restantes y el tiempo de expiración.

4. Seguridad

  • Validar todas las entradas de usuario relacionadas con el consumo y manipulación de ítems.
  • Implementar políticas de autorización para prevenir la manipulación no autorizada.

5. Mantenimiento

  • Implementar un sistema de limpieza periódica para eliminar o archivar ítems consumidos/expirados antiguos.
  • Registrar estadísticas sobre el uso y expiración de ítems para análisis.
